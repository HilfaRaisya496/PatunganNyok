# 🧾 PatunganNyok (SplitBill App)

PatunganNyok is a modern, offline-first mobile application built with Ionic and Angular. It helps friends, families, and colleagues easily and fairly split restaurant bills, including complex calculations for proportional taxes and service charges.

## ✨ Features
- **Fair Splitting:** Assign specific items to specific people so everyone only pays for what they ordered.
- **Auto-Calculations:** Automatically calculates proportional tax and service fees for each person.
- **Offline Support:** Fully functional without an internet connection (includes bundled local fonts).
- **Clean UI/UX:** A modern, intuitive, and responsive mobile interface.
- **Production Ready:** Successfully deployed to the Google Play Store using Android App Bundles (.aab).

## 🚀 Tech Stack
- **UI Components:** [Ionic Framework](https://ionicframework.com/)
- **Logic & Routing:** [Angular](https://angular.io/) (TypeScript/HTML)
- **Native Bridge:** [Capacitor](https://capacitorjs.com/) (for Android compilation)
- **Styling:** SCSS & CSS
